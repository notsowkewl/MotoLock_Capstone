# Verification changes rolled back

At the user's request, the original camera registration, unlock screen, dashboard, setup routing, Bluetooth service and DualAiAnalyzer were restored from the pre-change backups. The additional hold/capture flow and camera-only helpers were removed.

The Unlock Motorcycle button is hidden unless the original full setup requirements are complete. Original layouts and labels are restored.

This rollback restores the earlier behavior, including its existing model/enrollment limitations; it does not claim improved detection accuracy. No database records, model weights or hardware firmware were changed by this rollback.
